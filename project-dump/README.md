# Project dump

Drop new project material here: screenshots, images, videos, text notes, and links.
For multiple projects, use a separate subfolder for each one.

When ready, tell Codex which existing project to replace and which folder to use.
For example: “Use project-dump/my-new-project to replace Network Checker.”

Helpful details to include in a notes file:

- Project name and a short description
- What you built, why, and the tools you used
- Live demo or repository links
- Which image should be the main screenshot
- Any captions or details you want in the project write-up

This is an intake folder, not published site content. Adding files here does not
automatically change the website. When you request a replacement, Codex will use
the material to update the project listing and relevant detail page, and copy
the selected media into the site's public assets.

Only add material you intend to share; leave out credentials and private data.
