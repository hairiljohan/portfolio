# Portfolio

Documentation of the project layout and what lives in each folder.

## Project structure

- Root HTML files – Vite's entry points for the homepage and current project pages. Old project URLs redirect via `vercel.json`.
- `src/` – React and TypeScript source with custom CSS and CSS Modules.
  - `pages/` – Small entry files that select a page component and metadata key.
  - `mountPage.tsx` – Shared React mounting, metadata application, Analytics, and Speed Insights setup.
  - `App.tsx` – Homepage composition.
  - `components/` – Homepage sections and project page components.
    - `layout/` – Shared header, footer, and menu button.
    - `projects/` – Project layout, carousel, images, galleries, and interactive demos.
    - `beui/`, `arc/` – Locally adapted UI components, styles, helpers, and provenance notes.
  - `data/` – Current project, skills, hobby, and page metadata definitions.
  - `hooks/` – Persisted theme selection.
  - `utils/` – Document metadata helpers.
  - `styles/`, `index.css` – Global foundations and theme tokens; component styles are colocated CSS Modules.
  - `types.ts` – Shared content types.
- `public/` – Static assets served as-is.
  - `projects/` – Current project screenshots, cover artwork, and recordings.
  - `legacy/landingpage/` – Generated Launch Console demo; edit its source under `demos/` instead.
  - Favicons, robots, sitemap, theme initialization, social image, and compatibility assets.
- `demos/launch-console/` – Maintained standalone demo source.
- `scripts/` – Demo build and favicon generation tools.
- `tests/` – Node theme-initialization tests and Playwright browser tests.
- `project-dump/` – Project intake/reference material, outside the published site.
- `docs/`, `READMEs/` – Project documentation.
- `dist/` – Production build output generated by `npm run build`.
- `node_modules/` – Installed dependencies (generated by `npm ci`).
